# Anti-Slop Casio ClassWiz
- Chasis `#181E29`; LCD `#C8D6CD` / `#BDCEBE`; texto LCD `#1A2530`.
- SHIFT `#E5A93C`; ALPHA `#E05D5D`.
- PROHIBIDO botones o bordes azules/cian/morados en la UI. `#2563EB` solo dentro de LaTeX (`\textcolor`).
- Sin gradientes decorativos, glassmorphism ni sombras difusas: relieve plano de teclas físicas.
- Sin textos redundantes en teclas; solo serigrafía real Casio.
- Para estructura de teclado/LCD ver skill `casio-classwiz-ui`.
